    About the .com check. Every name is looked up over DNS-over-HTTPS. If the domain returns NXDOMAIN it almost certainly has never been registered, so we call it likely available. This is a strong hint, not a registrar lookup: a domain can be registered and simply not point anywhere, and it will still look free here. Always confirm at a registrar before you buy, and search a trademark database before you commit.

    Nothing is uploaded and nothing is stored. Names are built in your browser. The only thing that ever leaves this page is the bare domain name sent to a public DNS resolver so it can answer the availability question — no account, no email, no logging on our side. Turn the checkbox off and the tool never touches the network at all.
